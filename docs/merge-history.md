# Upstream merge history

Per-merge record of what this fork adopted from `agegr/pi-web` and what it declined,
with the reasoning. `AGENTS.md` keeps only the standing rules distilled from these
(section "Upstream merge decisions"); read the segment here before touching the files it
names. The machine-readable boundary is `scripts/fork-ownership.json`
(see [ownership-boundaries.md](ownership-boundaries.md)).

Merges before segment E are recorded in the git log.

> merge (`9d65248`) later recorded `6fcd7d4` as merged so `git merge-base` and
